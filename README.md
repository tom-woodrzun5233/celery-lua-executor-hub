## About Celery

Celery is a compact Windows desktop application for loading and executing Lua scripts in Roblox while keeping a larger script collection organized. Its design centers on a simple execution process, a lightweight interface, and convenient script hub access on Windows 10 and Windows 11.

The application brings together queued scripts, batch execution, automatic updating, and an embedded debugger in one workflow. With no-key access, multilingual interface support, and a built-in hub containing more than 500 scripts, Celery provides a practical Roblox script executor option for 2026.
